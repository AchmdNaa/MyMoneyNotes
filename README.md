# MyMoneyNotes

MyMoneyNotes adalah aplikasi Android sederhana untuk mencatat pemasukan dan pengeluaran harian.

## Fitur

- Menambah transaksi dengan nama, nominal (Rp), kategori, dan lokasi.
- Daftar transaksi dengan pencarian.
- Ringkasan laporan keuangan.
- Halaman profil yang dapat diubah.

## Teknologi

- Kotlin dengan Jetpack Compose dan Material 3.

## Cara Menjalankan

1. Buka folder proyek ini di Android Studio.
2. Tunggu proses *Gradle sync* selesai.
3. Pilih emulator atau HP Android, lalu klik **Run**.
